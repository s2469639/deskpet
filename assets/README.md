# 원본 캐릭터 자산

`mandu-reference.png`는 사용자가 올린 루트의 `1.png`와 바이트 단위로 동일합니다.
원본: 1620×2025 RGBA PNG, 배경 알파 0. 추출 과정에서 재생성하거나 다시 그리지 않습니다.

`deskpet/art.py`가 실행 시 아래 영역을 읽어 원래 비율로 렌더링합니다.

- 정면: x=78, y=1013, 폭=875, 높이=947 (빨간 안경 전신)
- 왼쪽 측면: x=29, y=60, 폭=770, 높이=836
- 오른쪽 측면: 왼쪽 측면을 실행 시 좌우 반전

288×352 투명 캔버스, 발 기준 y=320. 캐릭터 높이 288px를
설정된 90/120/180px로 표시하며 nearest-neighbor 보간을 사용합니다.
원본의 흰색 테두리, 렌즈 반사, 회색 눈동자와 팔·다리를 유지합니다.
눈 깜빡임은 눈 영역만 덮고, 나머지 움직임은 실행 시 작은 이동/비율 변화로 표현합니다.
진짜 발걸음 작화나 손으로 안경 고쳐 쓰기는 포함하지 않습니다.

원본 자체를 교체하면 위 추출 좌표도 함께 검토해야 합니다.
2.png(안경 없는 정면 포함)와 3.png(헤드폰)는 기본 프레임으로 사용하지 않습니다.
