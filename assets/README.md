# 스프라이트 자산

현재 폴더의 PNG 34장은 `deskpet/art.py`의 도트 드로잉으로 생성했습니다.
파일이 없으면 앱이 같은 프레임을 메모리에서 생성합니다.
첨부 이미지의 외형을 참고해 다시 그린 **임시 아트**이며 원본 추출본이 아닙니다.
원본 파일이 이 작업 공간에 제공되지 않아 원본 알파 채널은 확인하지 못했습니다.

원본 기반 프레임으로 교체할 때 이 폴더에 아래 이름의 PNG를 넣으세요.
모든 이미지는 **64×88, RGBA 투명 배경**, 도트 보간 없이 제작합니다.
서 있는 프레임은 발바닥을 y=79에 맞추고, 위쪽 8px는 점프 여백입니다.

- `idle-0.png` ~ `idle-5.png`: 정면 대기, 5번은 눈 감기
- `walk-left-0.png` ~ `walk-left-5.png`: 왼쪽 걷기
- `walk-right-0.png` ~ `walk-right-5.png`: 오른쪽 걷기
- `happy-0.png` ~ `happy-5.png`: 한 번 뛰기, 0·5번은 바닥
- `held-0.png` ~ `held-1.png`: 들리기
- `land-0.png` ~ `land-3.png`: 눌림에서 복원
- `sleep-0.png` ~ `sleep-3.png`: 눈 감고 졸기

일치하는 파일만 교체하고 나머지는 임시 아트를 사용합니다.
배경을 검정색으로 칠하지 말고 실제 알파 0으로 저장하세요.
헤드폰·안경 없는 이미지는 기본 자산으로 사용하지 않습니다.
